# סיכום העבודה

- ניקוי ועיבוד הנתונים, כולל היפוך פריטים (Reverse Coding) בשאלונים.
- חישוב ציונים כוללים ותתי-מדדים עבור טראומות ילדות (CTQ), הערכה עצמית (SE), חמלה עצמית (SCS) ובהירות תפיסה עצמית (SCC).
- ביצוע ניתוחי מתאם בין משתני המחקר המרכזיים.
- בניית מודלי רגרסיה לבחינת הקשר בין טראומות ילדות לבין מדדי החוסן הפסיכולוגי, תוך שליטה במשתנים דמוגרפיים ומשתני קשר זוגי.
- הערכת התרומה הייחודית של כל מנבא (ΔR²).
- יצירת ויזואליזציות של הנתונים, כולל גרפי פיזור ומפת חום של מתאמים.
- ביצוע ניתוחים אקספלורטוריים נוספים, השוואת מודלים ובדיקת ביצועי המודלים באמצעות Cross-Validation.
